# First_practice
# Hodgkin-Huxley Model Simulation

## 1. Project Overview
This project implements the Hodgkin-Huxley (HH) model
to simulate action potential generation in a neuron.

The model describes changes in membrane potential
through voltage-dependent sodium and potassium channels.

## 2. Objectives
- Understand the mathematical structure of the HH model.
- Implement the model using MATLAB.
- Investigate neuronal membrane potential dynamics.
- Analyze the effects of input current on action potential generation.

## 3. Model Components
The model includes three gating variables:

- m: Sodium channel activation
- h: Sodium channel inactivation
- n: Potassium channel activation

## 4. File Structure
- HH_FOR_GITHUB.m : Main HH model implementation

## 5. Requirements
- MATLAB

## 6. How to Run
1. Download or clone this repository.
2. Open the project folder in MATLAB.
3. Run HH_FOR_GITHUB.m.
